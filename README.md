# Browserkit

A personal collection of userscripts to simplify, customize, and improve the web.

## Scripts

| Script | What it does |
|---|---|
| Calm YouTube | Controls thumbnail colors, Shorts and comments; adjusts card sizes; filters Mix recommendations; adds pinned channels and a History shortcut. |

## Requirements

A browser with [Tampermonkey](https://www.tampermonkey.net/) installed.

## Development

Each userscript lives in the `scripts/` directory.
Changes are tracked in Git, with a version bump for each release.
